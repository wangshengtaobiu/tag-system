# LICENSE Recommendation

## Decision: MIT License

**Reasoning:**

1. **v0.1-stable is early-stage** — Apache-2.0's patent clauses and CONTRIBUTING requirements are premature
2. **MIT is the GitHub standard** — most recognizable, least friction for downstream users
3. **No patent-sensitive components** — the system uses standard LLM API calls and deterministic scripts
4. **9 lines vs 178 lines** — MIT is auditable by humans; Apache-2.0 requires legal review
5. **Can upgrade later** — switching from MIT to Apache-2.0 is possible in a future release (requires all contributors' consent)

## What MIT allows:

- Commercial use
- Modification
- Distribution
- Private use
- No liability

## What MIT does NOT include:

- Patent grant (Apache-2.0 has this)
- Trademark protection
- Contributor license agreement

## Recommendation stands.
